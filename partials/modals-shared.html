  1. Buka web ini menggunakan browser Google Chrome
    2. 
                      
  2. Klik ikon Titik Tiga  di pojok kanan atas layar
    3. 
                      
  3. Pilih menu "Tambahkan ke Layar Utama" (Add to Home Screen) 
    4. 
                      
  4. Klik Tambah. Aplikasi akan muncul di menu HP Anda!
    5. 
                  

              


              
              

                  
 iPhone (Safari)

                  
    
                      
  1. Buka web ini menggunakan browser Safari
    2. 
                      
  2. Klik ikon Share  di bagian bawah tengah layar
    3. 
                      
  3. Geser ke bawah, pilih "Tambah ke Layar Utama" (Add to Home Screen) 
    4. 
                      
  4. Klik Tambah di pojok kanan atas. Selesai!
    5.
