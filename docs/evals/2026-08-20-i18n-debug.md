## 2. tr() Function Analysis

```javascript
export function tr(path) {
  try {
    let obj = LANG[CURRENT_LANG];
    for (const p of String(path).split('.')) {
      obj = obj[p];
      if (obj === undefined) return path; // ← fallback ke key mentah
    }
    return obj;
  } catch (e) {
    return path; // ← fallback ke key mentah
  }
}
```

### ✅ Strengths

- **Fallback ke key**: Kalau key tidak ada, return key mentah → tidak crash
- **Null-safe**: `String(path)` handle undefined/null input
- **Dot-notation**: `tr('ui.cancel')` → `LANG[CURRENT_LANG].ui.cancel`

### ⚠️ Finding: Fallback silent (tidak warning)

- Kalau key typo, user melihat key mentah tanpa warning
- **Impact**: Developer tidak tahu ada key yang salah sampai user komplain
- **Verdict**: LOW — test `i18n.test.js` sudah catch typo (tr == key)
- **Recommendation**: Sudah cukup dengan test coverage

## 3. trOption() Function Analysis

```javascript
export function trOption(value) {
  if (value === null || value === undefined) return '';
  var s = String(value);
  var bar = s.indexOf('|');
  if (bar > -1) {
    var id = s.slice(0, bar).trim();
    var jp = s.slice(bar + 1).trim();
    return CURRENT_LANG === 'jp' && jp ? jp : id || s;
  }
  // ... fuzzy matching
}
```

### ✅ Strengths

- **Pipe syntax**: `"ID|JP"` format untuk inline translation
- **Fuzzy matching**: Handle emoji prefix, different casing
- **Null-safe**: Returns empty string for null/undefined

### ✅ Fuzzy Matching Logic

1. Exact match → `OPTION_TRANSLATIONS[value]`
2. Uppercase match → `OPTION_TRANSLATIONS[upper]`
3. Strip non-alpha prefix → `OPTION_TRANSLATIONS[stripped]`

## 4. toggleFormLanguage() Analysis

```javascript
export function toggleFormLanguage() {
  CURRENT_LANG = CURRENT_LANG === 'id' ? 'jp' : 'id';
  window.CURRENT_LANG = CURRENT_LANG;
  try {
    localStorage.setItem('asj_lang', CURRENT_LANG);
  } catch (e) {}
  if (typeof renderLanguageLight === 'function') renderLanguageLight();
  if (typeof window.renderLanguage === 'function') window.renderLanguage();
  if (typeof window.renderSysConfig === 'function' && document.getElementById('config-container'))
    window.renderSysConfig();
  if (typeof typeof window.rePopulateDropdowns === 'function') window.rePopulateDropdowns();
}
```

### ✅ Strengths

- **Persistence**: Simpan ke localStorage
- **Sync**: Update window.CURRENT_LANG accessor
- **Multi-render**: Panggil renderLanguageLight + renderLanguage + renderSysConfig + rePopulateDropdowns
